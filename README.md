## 🇹🇼 繁體中文

### ✨ 核心特色
* 🌐 **5 國語言即時切換**：繁體中文（連點器）、English（012 Auto Clicker）、日本語、한국어、简体中文。
* 💾 **熱鍵與全設定自動儲存**：設定好的熱鍵、自訂檔位、最後設定永久保存，重開機不遺失。
* 🎛️ **賽博霓虹發光滑桿**：高質感純黑膠囊跑道搭配發光霓虹進度條，支援 `[-5]` `[-1]` `[+1]` `[+5]` 科技微調。
* ⚡ **1 ~ 1,000 CPS 與極速狂暴模式**：微秒級混合等待演算法，支援超低延遲極限狂點。
* 🎮 **雙連點模式**：支援「按鍵切換 (按一下開/關)」與「按住狂點 (放開即停)」。
* 🛡️ **防封與安全雙守護**：
  - **真人微晃動 (防作弊)**：隨機時間微調，防止伺服器偵測外掛。
  - **滑鼠角落緊急煞車 (Fail-Safe)**：游標甩到螢幕左上角立刻秒停。
  - **ESC 隨時緊急中斷**：任何時候按下 ESC 瞬間煞車。
  - **自動停止限制**：可自訂點擊次數上限或連點最長秒數。

### 🚨 新手必看：系統阻擋排除與設定教學

由於本程式為開源自製工具，未向微軟或蘋果付費購買企業數位證書，**下載後第一次開啟時系統會跳出警告**，這是正常的保護機制，請依照下方步驟點擊即可正常使用：

#### 🍎 macOS 使用者

<details>
<summary><b>點此展開：Mac「無法打開」與「授權設定」教學（圖文指引）</b></summary>
<br/>

##### 1. 解決「無法打開，因為它來自未識別的開發者」
1. 下載 `012-AutoClicker-Mac.zip` 並連按兩下解壓縮出 `連點器.app`。
2. **請勿直接雙擊打開**，請對著 `連點器.app` **按滑鼠右鍵**（或按住鍵盤 `Control` 鍵點一下）。
3. 在選單中點選 **「打開」 (Open)**。
4. 系統會跳出提示視窗，點擊右下角的 **「打開」**，以後就能直接雙擊開啟了！

##### 2. 開啟 Mac 必要權限（確保連點與熱鍵正常）
Mac 為了安全，會限制背景程式監聽鍵盤與點擊，需開啟兩項權限：
1. 點選螢幕左上角蘋果  > **「系統設定」** > **「隱私權與安全性」**。
2. 點入 **「輔助使用」 (Accessibility)**：找到「連點器」並**打開開關**（若沒有，點下方 `+` 號加入 `連點器.app`）。
3. 點入 **「輸入監視」 (Input Monitoring)**：找到「連點器」並**打開開關**（負責全域熱鍵偵測）。
4. 設定完成後，將連點器徹底關閉（`Command + Q`）重新打開即可！

</details>

#### 🪟 Windows 10 / Windows 11 使用者

<details>
<summary><b>點此展開：Windows「藍色保護畫面」與「遊戲內按鍵」排除教學</b></summary>
<br/>

##### 1. 解決「Windows 已保護您的電腦」藍色畫面
1. 下載並解壓縮出 `AutoClicker.exe`。
2. 雙擊打開時，若彈出藍色視窗顯示「Windows 已保護您的電腦」 (SmartScreen)。
3. 點擊畫面文字中的 **「其他資訊」 (More info)**。
4. 右下角會出現按鈕，點擊 **「仍要執行」 (Run anyway)** 即可順利啟動！

##### 2. 解決遊戲中按熱鍵沒反應（必須以系統管理員身分執行）
* **原因**：部分全螢幕遊戲（例如 Minecraft、射擊遊戲）是以管理員權限運行的，普通權限程式無法把點擊輸入送進遊戲內。
* **解決方法**：
  1. 對著 `AutoClicker.exe` 按**滑鼠右鍵**。
  2. 點選 **「以系統管理員身分執行」** 即可。
  *(若想一勞永逸：右鍵 > 內容 > 相容性 > 勾選「以系統管理員身分執行此程式」 > 確定)*。

</details>

### 🚨 First-Time Setup & Security Bypass

#### 🍎 macOS
<details>
<summary><b>Click to expand: macOS Gatekeeper & Permissions Guide</b></summary>
<br/>

1. **Bypass "Unidentified Developer" Warning**:
   - Download and unzip `012-AutoClicker-Mac.zip`.
   - **Right-click** on `連點器.app` (or hold `Control` and click).
   - Select **Open**, then click **Open** again in the confirmation prompt.
2. **Grant System Permissions**:
   - Go to **Apple Menu  > System Settings > Privacy & Security**.
   - **Accessibility**: Toggle ON for `連點器`.
   - **Input Monitoring**: Toggle ON for `連點器` (required for global hotkeys).
   - Quit (`Command + Q`) and re-launch the app.

</details>

#### 🪟 Windows 10 & 11
<details>
<summary><b>Click to expand: Windows SmartScreen & Administrator Guide</b></summary>
<br/>

1. **Bypass "Windows Protected Your PC" (SmartScreen)**:
   - Double-click `AutoClicker.exe`.
   - Click **More info**.
   - Click **Run anyway**.
2. **In-Game Hotkey Not Triggering?**:
   - Games (like Minecraft) running with elevated privileges block standard key listeners.
   - **Right-click** `AutoClicker.exe` and choose **"Run as administrator"**.

</details>
